# Orbis 보고서 카피 가이드

> 사용자가 결제 후 받게 될 자기 분석 보고서의 톤 / 구조 / 작성 원칙.
> 메인 페이지의 후킹 카피와는 결이 다르다 — **분석가의 노트 톤**이지
> 광고 카피 톤이 아니다.

---

## 1. 두 가지 톤의 분리

Orbis는 두 가지 다른 톤을 동시에 운영한다. 섞이면 안 된다.

| 위치 | 톤 | 예시 |
|---|---|---|
| 메인 페이지 (Hero / About) | **후킹 카피** — 감성, 도발, "biting truth" | "왜 당신은 같은 사람한테 매번 끌릴까요?" |
| 보고서 안 (결제 후 받는 PDF) | **분석가의 노트** — 차트 데이터 인용, 정확한 진단 | "황소자리 28도의 금성을 가진 Jiwon님은…" |

- **후킹 카피**는 사람을 끌어들이는 미끼.
- **분석가의 노트**는 사주처럼 그 사람을 정확히 짚어주는 결.
- 결제 직전엔 후킹, 결제 후엔 분석. 보고서 안에서 후킹 톤이 나오면 짜쳐 보인다.

## 2. 보고서 페이지의 구조

각 챕터는 동일한 4블록 구조를 갖는다.

### 블록 1 — 후킹 헤드 + 캐릭터 부제

사주의 "정묘일주가 정재를 만났을 때" 같은 형식.
**한 줄 임팩트** + **차트 데이터를 받은 캐릭터 정의** 두 줄로.

```
끌릴수록 멀어지는 사랑.                  ← 한 줄 임팩트
황소자리 금성과 사자자리 화성이          ← 부제 (캐릭터 정의)
서로 다른 곳을 가리킬 때.
```

원칙
- 후킹은 **단정형**. 물음표 X, 마침표 O.
- 부제는 **차트 데이터를 캐릭터로 번역**. 점성술 용어 사용 OK.
- 시적이지만 모호하지 않다. 이 챕터를 한 줄로 요약하는 게 후킹의 역할.

### 블록 2 — 당신의 좌표 (COORDINATES)

차트 데이터를 한국어로 표기. 신뢰도 마크.

```
─ 당신의 좌표 ─
금성       황소자리 28° · 9번째 방
화성       사자자리 3° · 12번째 방
관계       금성과 화성, 90° 긴장
```

원칙
- 행성 / 별자리 + 도수 / N번째 방 형식 통일
- 각도 표기: `90°` `120°` `180°` (숫자 + 도) — "스퀘어" 같은 점성술 영어 X
- "12실" 대신 "12번째 방" — 한국어 자연스러움 우선
- 영문 기호 (☉ ☽ ♀ ♂) 보고서 안에선 사용 가능, About 같은 후킹 카피엔 X

### 블록 3 — 해석 (INTERPRETATION)

본문. 차트 데이터를 인용하면서 그 사람의 패턴을 정확히 짚는다.

```
황소자리 28도의 금성을 가진 Jiwon님은
사랑에 신중하고 흔들리지 않는 사람입니다.
한 번 마음을 정하면 쉽게 바꾸지 않는,
'천천히 깊어지는' 형태의 사랑을 합니다.

금성이 9번째 방 — 가치관과 신념의 자리에
머무는 배치는, 단순한 끌림이 아닌
'같은 세계를 바라보는 사람'에게서만
사랑을 느끼게 만듭니다.

…
```

원칙
- **이름 직접 호명** ("Jiwon님은") — 사주 톤. 본인을 바로 가리킨다.
- **각도까지 인용** ("황소자리 28도의 금성") — "황소자리 금성"이 아니라 정확한 도수.
- **하우스의 의미를 즉시 풀어준다** ("9번째 방 — 가치관과 신념의 자리").
  점성술 용어가 나오면 같은 줄에 한국어 풀이가 붙는다.
- **결론 먼저, 용어는 부가 설명**. 첫 줄은 진단, 그 다음에 근거.
- **두루뭉술 금지** — "당신은 감성적인 사람입니다" 같은 일반론은 즉시 폐기.
- **사주 비유는 절제** — "정관과 편관" 같은 비유는 친숙도엔 좋지만 점성술
  정체성을 흐릴 수 있어 정말 필요할 때만.
- **인용 카피 (시적 한 줄) 금지** — "당신은 사람들 앞에서 웃지만…" 같은
  후킹 카피는 보고서 본문에선 짜쳐 보인다.

### 블록 4 — 이 챕터의 항목 (IN THIS CHAPTER)

소제목 3-5개. 챕터가 다루는 세부 주제 미리보기.

```
01  끌리는 사람의 유형
02  당신이 다가가는 방식
03  반복되는 관계 패턴
04  가장 행복한 사랑의 형태
05  가장 다치게 하는 신호
```

원칙
- 각 챕터마다 3-5개의 세부 항목
- 명사형 / 짧게
- 폰 미리보기 화면에선 하단에 살짝 노출 + 페이드아웃 — "더 있다" 신호

## 5. 해서는 안 되는 것

### 본문에서 절대 쓰지 않는 표현
- "당신은 ~한 매력이 있어요"
- "오늘은 좋은 일이 생길 거예요"
- "별이 당신을 응원해요"
- "운명적으로 ~"
- "신비롭게 ~"
- "당신은 특별한 사람입니다"

### 보고서 안에서 빼야 할 것
- 메인 페이지의 후킹 카피 (시적 한 줄 인용 형식)
- 두루뭉술한 일반론
- 점성술 영문 용어 단독 (Sun in Cancer 같은 — 항상 한국어와 병기)
- 위로 / 응원 / 칭찬 톤

### 본문에서 선호하는 표현
- "당신의 좌표는 ~를 가리킵니다"
- "당신은 ~한 패턴을 반복합니다"
- "이 시기에 당신이 마주할 것은 ~입니다"
- "차트는 ~를 보여줍니다"

## 6. 사랑할 때 챕터 — 완성본 예시

전체 챕터의 본을 잡는 기준 예시.

```
Chapter IV
사랑할 때
When You Love

──────────────────────────────────
끌릴수록 멀어지는 사랑.
황소자리 금성과 사자자리 화성이
서로 다른 곳을 가리킬 때.
──────────────────────────────────

─ 당신의 좌표 ──
금성       황소자리 28° · 9번째 방
화성       사자자리 3° · 12번째 방
관계       금성과 화성, 90° 긴장

─ 해석 ──

황소자리 28도의 금성을 가진 Jiwon님은 사랑에 신중하고 흔들리지 않는
사람입니다. 한 번 마음을 정하면 쉽게 바꾸지 않는, '천천히 깊어지는'
형태의 사랑을 합니다.

금성이 9번째 방 — 가치관과 신념의 자리에 머무는 배치는, 단순한
끌림이 아닌 '같은 세계를 바라보는 사람'에게서만 사랑을 느끼게
만듭니다. 가벼운 만남에 흥미를 느끼지 못하는 이유가 여기 있습니다.

그러나 화성이 12번째 방, 무의식의 자리에 사자자리로 들어선 배치는
정반대 신호를 보냅니다. 사자자리 12실의 화성은 '밖으로 표현되지
않는 강렬함'을 의미합니다. 원하는 사람 앞에서 도리어 망설이고,
끌릴수록 거리를 두는 패턴이 반복되는 이유입니다.

두 행성이 90도로 맞물린 배치는, 사랑의 신중함(금성)과 표현의
망설임(화성)이 끊임없이 충돌하는 형국입니다. 좋아하는 사람일수록
다가가지 못한다는 패턴은, 의지의 문제가 아니라 차트에 새겨진 두
행성의 긴장 그 자체입니다.

─ 이 챕터의 항목 ──
01  끌리는 사람의 유형
02  당신이 다가가는 방식
03  반복되는 관계 패턴
04  가장 행복한 사랑의 형태
05  가장 다치게 하는 신호
```

## 7. AI 프롬프트 작성 시 체크리스트

Claude API에 차트 데이터를 보내 보고서를 생성할 때 프롬프트에 넣어야 할 강제 조건:

- [ ] 사용자 이름을 직접 호명 ("~님은")
- [ ] 각 단락의 첫 줄은 **진단(결론)** 으로 시작
- [ ] 차트 데이터(행성 / 별자리 / 도수 / 하우스 / 각도)를 본문에 직접 인용
- [ ] 점성술 용어는 같은 문장 안에서 한국어로 즉시 풀이
- [ ] 두루뭉술한 형용사 (감성적이다, 따뜻하다, 특별하다) 금지
- [ ] 단정형으로 작성 ("~합니다") — "~할 수도 있어요" 금지
- [ ] 위로 / 응원 톤 금지 — 진단서 톤으로
- [ ] 한 단락에 하나의 명확한 메시지
- [ ] 시적 인용 (큰따옴표로 한 줄 띄우는 형식) 금지
- [ ] 본문은 후킹용 광고 카피와 다른 톤으로
