# Orbis 서비스 기획서

> 유럽의 사주, 더 정밀하고 더 과학적인 자기 이해 도구

---

## 1. 서비스 개요

### 1.1 한 줄 정의
Orbis는 NASA 천체 데이터 기반의 자기 이해 리포트 서비스다. 출생 시간과 장소까지 반영한 진짜 점성술 차트(natal chart)를 분석해, 사용자에게 자신에 대한 깊고 정확한 분석 보고서를 제공한다.

### 1.2 서비스 컨셉
- **유럽의 사주**: 한국 사람들이 사주에 부여하는 신뢰도와 가치 인식을 가져오면서, 더 세련되고 과학적인 버전으로 포지셔닝
- **점치는 도구가 아닌 자기 이해 도구**: 운세가 아니라 좌표, 미신이 아니라 학문
- **"6월생이라고 다 같은 사람일 수 없다"**: 기존 별자리 운세의 잘못된 상식을 깨고, 진짜 점성술의 정밀도를 어필

### 1.3 차별화 포인트
1. 한국 시장에 비어있는 "도시적이고 지적인 자기 분석 도구" 자리 선점
2. 사주의 신뢰도 + Co-Star식 모던 브랜딩 + 한국형 결제 모델
3. 단순 운세가 아닌 A4 15-20장 분량의 깊은 보고서 형태
4. "그림자(약점)" 챕터로 차별화: 칭찬 대신 정확한 진단

## 2. 타겟 분석

### 2.1 핵심 타겟
20-30 여성

### 2.2 타겟 페르소나
- 사주의 가치는 알지만 사주 보러 가긴 올드하다고 느끼는 층
- MBTI는 졸업했고, 더 깊고 정확한 자기 이해 도구를 찾는 사람
- 인스타에서 Co-Star, Pattern 같은 앱을 공유하는 감성
- 자기 객관화에 진심이고, 좋은 콘텐츠엔 5천원~1만원 정도 쓰는 데 거부감 없음
- "엄마는 사주 보러 다니는데, 나는 좀 더 세련된 게 필요해" 인사이트

### 2.3 핵심 페인포인트
- 별자리 운세는 너무 가볍고, 사주는 너무 올드하다
- MBTI는 한계를 느꼈다 (16개 유형으로 사람을 나누는 한계)
- 친구한테 물어봐도 매번 같은 답, 누가 좀 명확하게 말해줬으면
- 자기 자신에 대한 확신이 필요한 시기 (관계, 커리어, 정체성)

## 3. 비즈니스 모델

### 3.1 수익 모델
건당 결제 (Pay per report)

### 3.2 상품 라인업

#### MVP 단계
- **"나 자신" 리포트**: 5,000원
  - 본인 정보만 입력 (진입 마찰 최소화)
  - A4 15-20장 분량의 자기 분석 보고서
  - 첫 결제 경험 만들기 + 결제 의향 검증

#### 확장 단계
- **"관계" 리포트**: 10,000원
  - 두 사람 차트 비교 분석
  - 끌림, 충돌, 풀어가는 법
  - 본인이 상대방 정보까지 입력 (시간 모르면 정오 디폴트)

- **"결혼 전 관계 리포트"**: 30,000~50,000원 (추후)
  - 결혼 키워드로 객단가 대폭 상승
  - 사주 궁합 시장 대체

- **"2026년 나의 1년 운명 리포트"**: 15,000~20,000원 (시즌 상품)
  - 연말~연초 한정 판매

### 3.3 광고 미운영
Co-Star 사례를 따라 광고 배제. "내면 분석 도구" 톤을 지키기 위해 광고 인벤토리 삽입하지 않음. 결제 전환에 집중.

## 4. 핵심 상품: "나 자신" 리포트 상세 기획

### 4.1 보고서 목차 (12장 구성)

**1장. 당신이라는 사람의 핵심 좌표**
- 태어난 순간 하늘 배치 시각화 (이미지 한 장)
- 핵심 에너지 3가지 요약
- 한 문장 정의

**2장. 당신의 세 가지 자아**
- 세상에 보여지는 나 (상승궁/Ascendant)
- 내가 인식하는 나 (태양/Sun)
- 무의식 속의 나 (달/Moon)
- 세 자아의 균형과 갈등

**3장. 당신의 감정 작동 방식**
- 달 별자리 기반 분석
- 스트레스 받을 때 반응 패턴
- 안정감을 찾는 방식
- 셀프케어 가이드

**4장. 당신이 사랑할 때**
- 끌리는 사람의 유형 (금성/Venus)
- 다가가는 방식 (화성/Mars)
- 관계에서 반복하는 패턴
- 가장 행복한 사랑의 형태
- 가장 다치게 하는 관계의 신호

**5장. 당신의 소통 방식**
- 수성(Mercury) 기반
- 말하고 듣는 패턴
- 오해받는 지점
- 갈등 상황에서의 패턴

**6장. 당신이 일할 때**
- 빛나는 환경 vs 시드는 환경
- 동료/상사로서의 모습
- 성공 공식
- 피해야 할 커리어 함정

**7장. 당신과 돈**
- 돈에 대한 무의식적 태도
- 소비 패턴
- 돈을 끌어당기는 방식

**8장. 당신의 그림자 (★ 핵심 차별화 챕터)**
- 회피하는 것
- 부정하는 것
- 반복되는 자기 파괴 패턴
- 가장 불편하지만 가장 가치 있는 챕터
- 칭찬이 아니라 정확한 비판

**9장. 당신의 재능과 사명**
- 타고난 재능
- 이번 생에서 풀어야 할 과제
- 의미 있는 톤으로 마무리 직전 위로

**10장. 지금 당신의 시기**
- 현재 행성 운행(transit) 기준
- 무엇이 끝나가는지, 무엇이 시작되는지

**11장. 앞으로 6개월**
- 시기별 키워드와 주의점
- 구체적 조언

**12장. 당신을 위한 처방**
- 기억해야 할 세 가지
- 매일 실천할 작은 행동
- 피해야 할 함정

### 4.2 보너스 섹션
- 당신의 행운의 색/숫자/요일 (가벼운 재미 요소)
- 당신과 잘 맞는 별자리 TOP3, 조심할 별자리 TOP3 (관계 리포트 크로스셀)
- 당신을 위한 책/영화 추천

### 4.3 보고서 작성 원칙
- **일반론 금지**: "당신은 감성적이고 따뜻한 사람입니다" 같은 표현 금지
- **구체적 묘사**: "당신은 사람들 앞에서 웃지만 집에 와서 그 대화를 다시 곱씹는 타입이에요" 같은 핀셋 묘사
- **단정형 문장**: "~할 수도 있어요" 가 아니라 "~합니다"
- **위로보다 정확함**: 칭찬이 아니라 진단

## 5. 사용자 플로우 및 페이월 설계

### 5.1 전체 플로우

**1단계: 입력 페이지**
- 이름, 생년월일, 출생 시간, 출생 장소 입력
- "정확한 시간을 모르면 분석 결과가 달라집니다" 안내
- 시간 모르면 부모님께 물어보세요 안내 (진지함 부여)

**2단계: 차트 생성 화면**
- 실제 차트 그려지는 애니메이션
- 행성들이 배치되는 시각화
- 단순 로딩이 아닌 천체 차트 그려지는 인터랙션
- "5천원 받을 수 있는 톤" 형성

**3단계: 무료 결과 페이지 (페이월 직전)**

무료로 보여줄 내용:
- 1장 전체 ("핵심 좌표" 다 공개)
- 2장 한 문단 (갭 묘사로 흥미 유발)
- 8장 그림자 티저 한 줄 (★ 결정타)
  - 예: "당신은 [구체적이고 약간 아픈 한 줄]. 왜 이런 패턴이 생겼는지, 어떻게 풀어야 하는지는 전체 리포트에서 확인하세요."
- 전체 12장 목차 미리보기 (각 챕터 첫 줄만 + 나머지 블러)

**4단계: 페이월**
- "전체 리포트 보기 5,000원" 버튼
- 카피 후보 (A/B 테스트):
  - "왜 당신이 매번 같은 사람한테 끌리는지, 차트에 답이 있어요"
  - "당신이 인정하기 싫은 그 패턴, 12장에 다 적혀있어요"
  - "내 인생 처음 보는 정확한 나에 대한 분석"

**5단계: 결제 후**
- 웹에서 즉시 풀 리포트 열림
- 이메일로 PDF 동시 발송 (가치감 향상)
- "당신이라는 세계가 도착했습니다" 메시지

### 5.2 페이월 설계 원칙
- 무료 영역에서 두 가지 동시 제공: "이거 진짜네" 신뢰 + "더 보고 싶다" 갈증
- 그림자 티저가 결제 전환의 핵심
- 일반론 절대 금지, 그 사람 차트 데이터 기반 구체적 한 줄 필수

## 6. 브랜드 톤앤매너

### 6.1 브랜드 한 줄 정의
Orbis는 위로하지 않는다. 정확하게 말한다. 점치지 않는다. 좌표를 읽는다.

### 6.2 네이밍
- **브랜드명**: Orbis (오르비스)
- **어원**: 라틴어로 "원, 궤도, 세계"
- **의미**: 천문학적 + 더 큰 세계관 함의

### 6.3 슬로건
- 메인 슬로건: "당신이라는 세계"
- 포지셔닝 슬로건: "유럽의 사주"
- 서브 카피: "6월생이라고 모두 같은 사람일 수 없습니다"

### 6.4 비주얼 톤

**컬러 팔레트**
### 컬러
- 배경: `#000000` 또는 `#0A0E1A` (딥 네이비-블랙)
- 메인 텍스트: `#FFFFFF` (opacity 100%)
- 서브 텍스트: `#FFFFFF` (opacity 70%)
- 보조 텍스트: `#FFFFFF` (opacity 40%)
- 비활성/힌트: `#FFFFFF` (opacity 20%)
- 모든 강조는 흰색 opacity 차이로만 처리. 별도 컬러 액센트 사용 금지.

**무드**
- 차갑고, 도시적이고, 미니멀
- 인터스텔라적인 깊이감 있는 우주
- 다른 차원에 있는 듯한 감각

**일러스트 스타일**
- 행성 궤도 라인
- 천체 차트
- 미니멀한 별의 점들
- 깊이감 있는 우주 그래픽

**금지 요소**
- 핑크/퍼플 컬러
- 반짝이 효과
- 큐티한 일러스트
- 손글씨 폰트
- 별 캐릭터화

**폰트**
- 영문: Playfair Display (세리프, 헤드용) + Inter (산세리프, 본문용)
- 한글: Pretendard 또는 Noto Sans KR

### 6.5 보이스 톤

**3대 원칙**

1. **단정형으로 말한다**
   - "~할 수도 있어요" → "~합니다"
   - 모호함 제거, 확신이 신뢰를 만든다

2. **위로보다 정확함을 택한다**
   - "당신은 특별해요" 같은 달콤한 말 금지
   - "당신은 사람들 앞에서 웃지만, 집에 와서 그 대화를 다시 곱씹는 사람입니다"

3. **시적인 헤드 + 분석적인 본문**
   - 헤드라인은 묵직하고 시적으로
   - 본문은 차갑고 명료하게

### 6.6 표현 가이드

## 7. 기술 스택

### 7.1 전체 아키텍처
Next.js 풀스택 + Vercel 배포

### 7.2 구성 요소

**프론트엔드 + 백엔드**
- Next.js (App Router)
- Tailwind CSS
- 배포: Vercel

**천체 차트 계산**
- JS 라이브러리 활용 (`swisseph` 또는 `astronomia` npm 패키지)
- 외부 서버 없이 Next.js API route 내에서 처리

**AI 분석 텍스트 생성**
- Claude API
- 차트 데이터를 Claude에 전달 → 12장 보고서 텍스트 생성

**결제**
- Toss Payments 또는 카카오페이 연동
- 건당 결제 (구독 X)

**데이터베이스**
- Vercel Postgres 또는 Supabase (사용자 정보, 결제 내역)

**이메일 발송**
- Resend 또는 Sendgrid (PDF 첨부)

**PDF 생성**
- Puppeteer 또는 react-pdf

### 7.3 핵심 데이터 플로우
```
유저 입력 (이름, 생년월일시, 장소)
  ↓
JS 라이브러리로 natal chart 계산
  ↓
계산 결과를 Claude API에 전달 (프롬프트 엔지니어링)
  ↓
12장 보고서 텍스트 생성
  ↓
웹 결과 페이지 + PDF 생성
  ↓
이메일 발송 + DB 저장
```

### 7.4 개발 우선순위
1. natal chart 계산 로직 검증
2. Claude API 프롬프트 튜닝 (★ 가장 시간 많이 소요, 서비스 퀄리티 결정)
3. 무료 영역 + 페이월 UI/UX
4. 결제 연동
5. PDF 생성 + 이메일 발송
