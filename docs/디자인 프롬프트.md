# Orbis 메인페이지 디자인 - 클로드 코드용 프롬프트

## 프로젝트 컨텍스트

Next.js 14 (App Router) + Tailwind CSS 기반의 메인 랜딩 페이지를 만들어주세요.

서비스명은 **Orbis (오르비스)** 이며, "유럽의 사주"를 컨셉으로 한 NASA 천체 데이터 기반 자기 이해 리포트 서비스입니다. 타겟은 20-30 여성입니다.

이 페이지는 단순한 랜딩이 아니라, 첫 3초 안에 "이거 뭔가 다른 서비스다"라는 인식을 만들어야 합니다. Co-Star, Pattern, Linear, Arc Browser 같은 미니멀하고 도시적인 톤을 참고해주세요.

---

## 디자인 원칙 (절대 위반 금지)

### 컬러
- 배경: `#000000` 또는 `#0A0E1A` (딥 네이비-블랙)
- 메인 텍스트: `#FFFFFF` (opacity 100%)
- 서브 텍스트: `#FFFFFF` (opacity 70%)
- 보조 텍스트: `#FFFFFF` (opacity 40%)
- 비활성/힌트: `#FFFFFF` (opacity 20%)
- 모든 강조는 흰색 opacity 차이로만 처리. 별도 컬러 액센트 사용 금지.
### 폰트
- 영문 헤드라인: Playfair Display (Google Fonts에서 import)
- 영문 본문: Inter (Google Fonts에서 import)
- 한글: Pretendard (cdn.jsdelivr.net/gh/orioncactus/pretendard 에서 import)
- 헤드라인은 영문 세리프 + 한글 산세리프 조합으로 묵직함과 모던함 동시에

### 금지 요소 (절대 사용 금지)
- 핑크, 퍼플, 네온 컬러
- 반짝이 효과, 글리터, 스파클 애니메이션
- 큐티한 일러스트, 캐릭터, 이모지
- 손글씨 폰트, 둥근 폰트
- 그라데이션 배경 (단, 깊이감을 위한 매우 어두운 톤 그라데이션은 허용)
- 둥근 모서리 과도하게 (border-radius 4-8px 정도까지만)

## 페이지 구조

### 1. Hero Section (첫 화면)

**레이아웃**
- 풀스크린 (100vh)
- 중앙 정렬, 좌측 정렬 혼합 가능
- 깊은 우주 배경 (Three.js 또는 Canvas로 별과 행성 렌더링)

**배경 동적 요소 (중요)**
- 검은 우주 배경에 미세하게 빛나는 별들 (200-300개 정도)
- 별들은 각자 다른 속도로 천천히 깜박임 (opacity 0.3 ~ 1.0 사이)
- 중앙에서 약간 벗어난 위치에 천체 궤도 라인이 천천히 회전
- 마우스 움직임에 따라 배경이 살짝 시차(parallax)로 움직임 (10-20px 정도)
- 너무 화려하지 않게, 인터스텔라 영화 같은 무겁고 깊은 우주감

**카피 구성**
```
(상단 작은 라벨, 골드 컬러)
유럽의 사주

(메인 헤드라인, 큰 사이즈, 한글)
당신이라는 세계

(서브 헤드라인, 중간 사이즈)
6월생이라고 모두 같은 사람일 수 없습니다.

(본문, 작은 사이즈, 회색)
당신이 태어난 그 시간, 그 장소.
하늘의 모든 좌표가 당신을 만들었습니다.
Orbis는 NASA 천체 데이터로
당신이라는 세계를 읽습니다.

(CTA 버튼)
내 좌표 확인하기
```

**카피 등장 모션**
- 페이지 로드 시 각 텍스트가 0.3초씩 시차를 두고 페이드인
- 살짝 아래에서 위로 올라오는 모션 (translateY 20px → 0)
- 라벨 → 헤드라인 → 서브 → 본문 → CTA 순서
- easing은 cubic-bezier(0.16, 1, 0.3, 1) 같은 부드러운 곡선

**CTA 버튼 스타일**
- 배경 투명, 흰색 테두리 1px
- 호버 시 배경 흰색, 텍스트 검정으로 반전
- 화살표 아이콘이 호버 시 살짝 오른쪽으로 이동
- 너무 크지 않게, 미니멀하게

### 2. Section 2 - 차별화 섹션 ("진짜 별자리란?")

**레이아웃**
- 화면 절반: 좌측 비주얼, 우측 텍스트 (또는 반대)
- 풀스크린 또는 80vh

**좌측 비주얼**
- 실제 천체 차트(natal chart) SVG 일러스트
- 12개 별자리가 원형으로 배치된 차트
- 행성 심볼들이 차트 위에 점으로 표시
- 마우스 호버 시 각 행성에 라벨이 떠오름
- 차트가 천천히 회전 (60초에 한 바퀴 정도, 거의 안 보일 정도로 느리게)

**우측 텍스트**
```
(라벨)
HOW IT WORKS

(헤드라인)
당신이 알던 별자리는
12개 중 하나가 아닙니다

(본문)
태양 별자리만 본다면 70억 명이 12가지 사람으로 나뉩니다.
하지만 당신이 태어난 순간, 행성들은 각자의 자리에 있었고
그 배치는 당신만의 것입니다.

Orbis는 출생 시간과 장소까지 반영한
당신만의 천체 좌표를 계산합니다.
```

**스크롤 인터랙션**
- 이 섹션 진입 시 좌측 차트가 한 번에 그려지는 SVG 애니메이션
- stroke-dasharray 속성을 활용한 라인 드로잉 효과
- 텍스트는 우측에서 페이드인

### 3. Section 3 - 보고서 미리보기

**레이아웃**
- 풀스크린, 중앙 정렬
- 보고서의 12개 챕터를 카드 형태로 그리드 배치

**구성**
```
(라벨)
WHAT YOU'LL DISCOVER

(헤드라인)
12개의 좌표, 당신이라는 세계의 지도

(서브)
A4 15-20페이지의 깊은 분석. 일반론이 아닌 당신만의 진단.
```

**12개 챕터 카드**
- 3x4 또는 4x3 그리드
- 각 카드: 검은 배경 + 얇은 흰색 테두리 + 챕터 번호 + 챕터 제목
- 호버 시 카드가 살짝 확대 (scale 1.02) + 테두리 골드로 변화
- 카드 내용:
  1. 핵심 좌표
  2. 세 가지 자아
  3. 감정 작동 방식
  4. 사랑할 때
  5. 소통 방식
  6. 일할 때
  7. 돈과의 관계
  8. 그림자
  9. 재능과 사명
  10. 지금 이 시기
  11. 앞으로 6개월
  12. 당신을 위한 처방

**스크롤 인터랙션**
- 카드들이 시차를 두고 하나씩 페이드인 (각 0.05초 간격)

### 4. Section 4 - 신뢰 요소 섹션

**레이아웃**
- 풀스크린, 중앙 정렬
- 3개 컬럼 가로 배치

**구성**
```
(헤드라인)
Orbis가 다른 이유

3개 컬럼:
- NASA 천체 데이터
  실시간 갱신되는 행성 좌표를 그대로 사용합니다.

- 분 단위 정밀 분석
  출생 시간 1분 차이가 당신의 좌표를 바꿉니다.

- 일반론 없는 진단
  당신만을 위한 구체적인 분석. 칭찬 아닌 정확함.
```

**비주얼**
- 각 컬럼 상단에 미니멀한 SVG 아이콘 (선으로만 그려진)
- NASA: 작은 위성 또는 지구 라인
- 분 단위: 시계 또는 좌표 라인
- 진단: 거울 또는 X자 좌표

### 5. Section 5 - Final CTA

**레이아웃**
- 풀스크린, 중앙 정렬
- 다시 우주 배경

**구성**
```
(헤드라인, 매우 큰 사이즈)
당신이라는 세계,
이제 펼쳐보시겠습니까?

(본문)
태어난 시간과 장소만 있으면 됩니다.
3분 안에 당신만의 좌표가 그려집니다.

(CTA 버튼, 큰 사이즈)
내 좌표 확인하기 →

(작은 텍스트)
첫 결과는 무료입니다.
```

### 6. Footer

**레이아웃**
- 작고 미니멀하게
- 검은 배경, 회색 텍스트

## 기술 구현 가이드

### 라이브러리
- `framer-motion`: 모든 페이드인, 스크롤 인터랙션
- `three.js` 또는 `@react-three/fiber`: 우주 배경 별/행성 렌더링
- `lenis` 또는 native smooth scroll: 부드러운 스크롤
- Tailwind CSS: 모든 스타일링
- 폰트: next/font 활용

### 성능 최적화
- 별 파티클은 GPU 활용 (Three.js Points 또는 Canvas)
- 이미지/SVG는 lazy loading
- 모션은 `will-change` 적절히 사용
- 모바일에서는 파티클 수 줄이기, parallax 비활성화

### 반응형
- 데스크톱: 풀 비주얼 + 인터랙션
- 태블릿: 레이아웃 유지, 폰트 크기 축소
- 모바일: 단일 컬럼, parallax 비활성화, 별 개수 50% 축소
- 모바일 헤드라인 폰트는 데스크톱 대비 60% 정도

### 접근성
- 모든 모션은 prefers-reduced-motion 미디어 쿼리 대응
- 컬러 대비 충분히 (WCAG AA 기준)
- 시맨틱 HTML 구조 유지

## 톤 디테일 (놓치면 안 될 것들)

### 마이크로 인터랙션
- 모든 호버는 0.3초 ease-out
- 클릭 시 아주 살짝 scale down (0.98)
- 링크 호버 시 underline이 좌→우로 그려지는 효과
- 버튼 호버 시 화살표가 살짝 이동

### 여백
- 섹션 간 여백 충분히 (각 섹션 풀스크린 또는 최소 80vh)
- 텍스트 라인 높이 1.6 이상
- 헤드라인 letter-spacing 약간 좁게 (-0.02em)
- 본문은 letter-spacing 0 또는 약간 넓게

### 텍스트 위계
- 헤드라인: 영문 Playfair Display Bold + 한글 Pretendard SemiBold
- 서브 헤드라인: 한글 Pretendard Medium
- 본문: Pretendard Regular
- 라벨: Inter Medium, uppercase, letter-spacing 넓게 (0.1em)

### 디테일
- 스크롤 인디케이터 (Hero 하단에 작은 화살표 + "scroll" 텍스트)
- 페이지 상단에 스크롤 진행도 바 (얇은 흰색 라인, opacity 0.3)
- 커서 호버 시 살짝 변화 (선택적, 너무 과하면 안 됨)
